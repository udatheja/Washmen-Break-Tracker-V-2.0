📌 Overview

The Washmen Wash & Fold Break Time Tracker is a custom-built workforce management application designed to simplify employee break tracking, improve operational transparency, maintain fair break-time allocation, and help supervisors monitor overtime across Morning and Night shifts.

The system provides a centralized dashboard for managing employee break schedules, monitoring active break timers, recording break activities, identifying overtime exceptions, and generating operational reports.

Developed with a focus on real-world laundry operations, the application transforms manual break monitoring into a structured, digital, and data-driven workflow.

✨ Key Features

⏱️ 1. Real-Time Break Tracking

- Start and monitor employee break sessions.
- Live countdown timers for active breaks.
- Automatic tracking of elapsed break duration.
- Visual break status indicators.
- Break duration and overtime monitoring.
- Alerts for approaching and exceeded break limits.
- Detection of unusually long-running break sessions.

👥 2. Employee Management

- Dedicated Wash & Fold employee roster.
- Employee identification numbers and names.
- Morning and Night shift assignments.
- Add new employees to the roster.
- Edit employee information.
- Search employees by name or ID.
- Filter employees by shift.
- Remove employees when necessary.

📊 3. Supervisor Dashboard

- Centralized operational monitoring.
- Live active break overview.
- Today's shift break matrix.
- Employee break utilization monitoring.
- Break status visibility:
  - Pending
  - In Progress
  - Taken
- Supervisor-controlled break adjustments.
- Password-protected administrative operations.

📋 4. Daily Break Logs & Audit Trail

- Automatic recording of break activities.
- Employee identification and shift information.
- Break start and end times.
- Actual break duration.
- Allowed break duration.
- Positive or negative time variance.
- Supervisor exception notes.
- Review flags for unusual break records.
- Filtering by date, shift, break type, and employee.
- Exportable break records.

📈 5. Monthly Adherence & Variance Reports

A dedicated reporting dashboard designed to evaluate break-time compliance and operational performance.

Reporting capabilities include:

- Monthly break adherence summaries.
- Morning and Night shift comparisons.
- Total employee break consumption.
- Monthly entitled break time.
- Net break-time variance.
- Overtime and critical violation indicators.
- Employee-level performance breakdown.
- Monthly CSV report export.

⚙️ 6. Custom Shift & Break Settings

Configurable operational settings provide flexibility when managing different shift requirements.

Available configurations include:

- Morning and Night shift schedules.
- Individual break allocations.
- Custom break durations.
- Break monitoring warning thresholds.
- Grace periods.
- Overtime alert thresholds.
- Maximum simultaneous active breaks.
- Configurable break time windows.
- Audio alert preferences.
- Test Mode for controlled testing.

🔐 7. Supervisor Controls & Operational Governance

- Password-protected supervisor settings.
- Employee break reset and adjustment.
- Manual break timer launch.
- Supervisor exception recording.
- Operational reason and context notes.
- Daily dashboard reset.
- Protected factory roster restoration.

💾 8. Backup & Data Management

Built-in data portability features help protect operational records.

- Download complete JSON database backups.
- Restore data from JSON backup files.
- Share backups through Android sharing options.
- Export daily break logs as CSV.
- Export monthly summaries as CSV.
- Google Sheets-compatible CSV exports.
- Support for transferring backups between Android devices and PCs.

🔒 Data & Privacy Considerations

The packaged application uses browser-based storage and provides manual JSON backup and restoration functionality.

Important considerations:

- Application records are stored locally in the browser environment.
- Clearing browser storage or changing browser profiles may affect saved records.
- Back up important operational data regularly.
- JSON backups should be stored securely.
- CSV exports may contain employee information and should be handled responsibly.
- No centralized cloud database or automatic multi-device synchronization is documented in this release.
